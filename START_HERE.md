# START HERE

1. Open this whole folder in VS Code.
2. Terminal: `python3 -m http.server 5500` (Windows: `py -m http.server 5500`).
3. Browser: `http://localhost:5500` — the included demo demonstrates the games, not an actual exam.
4. VS Code AI Chat → Agent mode → paste:

> Read AGENTS.md. Create and activate a complete Fast-Track Cram Hub for **[CERTIFICATION NAME]**. Verify the current official exam guide, write unique exam-specific questions, lessons and exercises for EVERY existing module, update `certifications/registry.json`, validate and test. Reuse the current HTML/CSS/JS website, preserve other packs/progress, and do not build a new application.

5. Refresh the browser. Select your new exam. To add another, repeat step 4 with a different name.

See `README.md` for details and `.gitignore` for what not to upload to GitHub.
